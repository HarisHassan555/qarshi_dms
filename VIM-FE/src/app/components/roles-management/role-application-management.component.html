Only administrators can configure which applications each role sees on the All Applications page.

Each role has one visibility rule on All Applications. Use Add New Rule for a role that does not have one yet. Use the row icons to edit or delete. Each field accepts multiple values. An application matches if it fits any selected value in a field, and every field that has a selection. Leave a field empty for any value. A role with no rule sees all applications.
